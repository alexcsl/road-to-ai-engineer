# Road to AI Engineer

A public, evidence-driven record of a **12-week intensive AI Engineer sprint** (starting 2026-11-16).

**Goal:** Independently design, train, evaluate, optimize, deploy, and defend real AI systems. AI coding agents accelerate routine work; engineering decisions, experimental rigor, and technical understanding remain human-owned.

## Working principles
1. Understand → Design → Implement → Experiment → Evaluate → Defend.
2. Maintain leakage-safe splits, baselines, reproducibility, tests, and honest limitations.
3. Log actual commands, results, configurations, failed experiments, and lessons learned.
4. Mark tasks **verified** only when supporting artifacts or test evidence exist.
5. Commit small, meaningful changes. Prefer progress over commit streaks.

## Layout
`projects/` contains independent implementations and evaluations; `journal/week-XX/day-XX.md` captures daily learning; `SPRINT_PROGRESS.md` tracks the current verified state.
