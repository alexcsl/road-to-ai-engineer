## Daily engineering cycle
**Understand → Design → Implement → Experiment → Evaluate → Defend.**

Each day: learn critical mechanisms, design deliberately, implement with tested code, run comparisons, interpret evidence, independently defend decisions. Commit meaningful increments and record commands, results, failures, lessons and the next verified gate.

**Do not prefill future journals with fake results or award yourself mastery.** Week plans are *specifications*; only code/tests/journal evidence establishes actual progress.
