# 12-Week AI Engineer Sprint

**Start:** 2026-11-16. **Target finish:** 2027-02-07 (12 seven-day weeks). **Pace:** target 35–45 focused hours/week, adjusted for university obligations.

The schedule is a plan; completion depends on evidence and acceptance gates, not calendar dates.

| Weeks | Focus | Target evidence |
|---|---|---|
| 01–02 | Classical ML | Fraud detection baseline, leakage-safe split, comparison, error analysis, tested inference API |
| 03–04 | Deep Learning & Computer Vision | PyTorch training loop, CNN and transfer learning comparison, evaluated vision demo |
| 05–06 | NLP & LLM Engineering | Transformer baseline, appropriate fine-tuning, held-out evaluation, model card |
| 07–09 | RAG & Agentic AI | Multilingual document intelligence, retrieval baselines, grounded citations, failure testing |
| 10–11 | MLOps & Production AI | CI, model/data versioning, monitoring, deployment, reproducible performance benchmarks |
| 12 | Portfolio & External Validation | Working demos, technical case studies, independent review, targeted applications |

## Universal quality gate
- Explicit problem definition and appropriate baseline
- Justified data split with leakage controls
- Repeatable runs with recorded dependencies and configurations
- Meaningful task-specific metrics and error analysis
- Tested maintainable implementation and honest limitations
- Technical defense: explain, debug, or modify core components unaided

## Week 1 (November 16–22): Classical ML experiment design
- Day 01: Dataset provenance, exploratory analysis plan, class imbalance, metrics, protocol
- Day 02: Split strategy and train-only preprocessing, leakage tests
- Day 03: Dummy and logistic regression baselines
- Day 04: Random forest, comparison, overfitting analysis
- Day 05: LightGBM, bounded training and comparison
- Day 06: Threshold selection, calibration, error analysis and ablation
- Day 07: Freeze model, final held-out evaluation, reproducibility and defense

Week 2 extends to inference API, tests, packaging, deployment, and case study. Adapt specifics based on actual Week 1 evidence.
