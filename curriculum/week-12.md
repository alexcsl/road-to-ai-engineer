# Week 12 — Portfolio — engineering proof, external validation and interviews
**Planned start:** 2027-02-01 · **Project:** `portfolio (all projects)` · **Status:** Planned syllabus, not actual progress
**Weekly result:** Four auditable portfolio artifacts, credible public case studies and documented outreach without inventing external validation.

## Daily curriculum

### Day 01 — Repository integrity audit
- **Learn:** Reproducibility and source-of-truth documentation.
- **Implement:** Review all project READMEs, licenses, test instructions, data/model provenance and links.
- **Experiment/evaluate:** Check sample runs and no secret/PII leaks.
- **Defend independently:** Defend architecture of each project.
- **Pass when:** List release blockers and evidence references.

### Day 02 — ML and CV case studies
- **Learn:** Methodology communication and negative-result honesty.
- **Implement:** Write concise ML + CV reports with baseline and experiment comparisons.
- **Experiment/evaluate:** Verify numbers and plots against stored outputs.
- **Defend independently:** Explain strongest and weakest findings of each.
- **Pass when:** Two evidence-backed case studies.

### Day 03 — NLP/LLM case study
- **Learn:** Model cards, PEFT tradeoffs, multilingual evaluation.
- **Implement:** Publish fine-tuning process, model card, license constraints and inference demo guidance.
- **Experiment/evaluate:** Revalidate reported evaluation against actual logs.
- **Defend independently:** Explain why fine-tuning vs prompt-only approach.
- **Pass when:** NLP model evidence packaged.

### Day 04 — Flagship demo
- **Learn:** User-centered product proof, system architecture and security boundaries.
- **Implement:** Prepare document AI walkthrough, architecture diagram, API demo and adversarial examples.
- **Experiment/evaluate:** Run smoke checks; verify citations and no private data exposure.
- **Defend independently:** Trace full data/authorization path unaided.
- **Pass when:** Working reproducible demo or explicit access limitation.

### Day 05 — External technical review
- **Learn:** Issue triage, feedback quality, OSS etiquette.
- **Implement:** Request approval before outreach; prepare review request; identify concrete upstream issue/PR.
- **Experiment/evaluate:** Track actual reviewer responses separately from requests.
- **Defend independently:** Respond to a skeptical architecture critique.
- **Pass when:** Review outreach prepared; real acceptance only when evidenced.

### Day 06 — Hiring evidence
- **Learn:** Job relevance, ATS truthfulness, interview readiness.
- **Implement:** Map projects to verified AI Engineer requirements; create concise resume bullets and interview stories.
- **Experiment/evaluate:** Self-administer timed PyTorch, ML eval, RAG debugging and design exercises.
- **Defend independently:** 20-minute independent architecture interview.
- **Pass when:** Role-aligned portfolio and defense gap list.

### Day 07 — Sprint audit and next plan
- **Learn:** Retrospective, realism, independent ownership.
- **Implement:** Compile achieved vs planned milestones, verified results, gaps, next 4-week plan.
- **Experiment/evaluate:** Review tests/reports and unresolved P0/P1 defects.
- **Defend independently:** Live technical presentation covering data→deployment.
- **Pass when:** Final sprint audit completed with no fabricated outcomes.
